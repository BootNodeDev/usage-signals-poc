Usage Signals

A working prototype you can try

Usage Signals is a shared web and API analytics service for projects built on Stellar. Open a sample site, browse a few pages, then see the visit in that project's console and in the operator view.

1. Visit a sample site

Three sample sites carry the tracker. Each page view goes through our gateway before it reaches Umami.

  • Demo site B
  • Demo site C

2. See it as the project

What a project sees for its own site: page views, visitors, referrers, visit duration, bounce rate, countries, devices and browsers.

  • Console of Demo site A
  • Console of Demo site B
  • Console of Demo site C

3. See it as the operator

What SCF sees across projects: comparable totals, with small counts shown as fewer than 10.

  • Operator view of all projects

What this prototype is

The web path runs end to end. There is no sign-in: the address picks the project. Most of the figures come from generated sample traffic, loaded so the views have something to show. API analytics was tested as a local experiment and is not in this deployment; the repository lists every check and its result.

Prototype for the SCF RFP "Web and API Analytics for Stellar Ecosystem Projects". Apache-2.0.
